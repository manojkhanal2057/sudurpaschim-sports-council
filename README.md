# सुदूरपश्चिम प्रदेश युवा परिषद् — Frontend

A responsive, static multi-page government-style website built with HTML, CSS and vanilla JavaScript. No framework or build step is required.

## Run locally
- Open this folder in VS Code.
- Recommended: install the **Live Server** extension and select `index.html` → **Open with Live Server**.
- Or run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

Opening via `file://` may work for this static site, but a local server is recommended.

## Pages
- `index.html` — Home
- `about-us.html` — About, vision and objectives
- `staffs.html` — Officials and staff
- `notices.html` — Searchable notices
- `programs.html` — Youth programs
- `policies.html` — Laws and policies
- `gallery.html` — Photo gallery
- `contact.html` — Contact and demo inquiry form
- `charter.html` — Citizen charter
- `structure.html` — Organization structure

## Before production deployment
This is a frontend-only implementation. The inquiry form does not submit to a server; connect it to an approved API/backend and add server-side validation, spam protection, privacy notice and secure storage before launch. Replace placeholder profile/gallery imagery, verify the current names and positions of officials, confirm the office contact details, and attach the official PDF/download links for notices and legal documents. Do not publish placeholder details as official facts. Confirm all public information with the council before deployment.

## Design notes
- Responsive mobile navigation
- Shared header and footer generated by `assets/js/main.js`
- Working page navigation and footer links
- Search filter on notices page
- Accessible labels and status feedback on demo contact form
- Nepali-first typography with a restrained government blue/red palette
